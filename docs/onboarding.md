# 처음 시작하기

이 안내의 목표는 메모를 바탕으로 첫 발표자료를 만들고 직접 열어 보는 것입니다. Figma 편집과 PDF 제작은 그다음에 필요한 경우 이어갑니다. 예시는 ‘팀 회의 메모로 5장짜리 발표자료 만들기’이며, 실제 내용은 사용자가 준비한 자료로 바꾸면 됩니다.

## 1. 사용할 AI 준비하기

이 플러그인은 Claude Code 또는 Codex에서 사용합니다. 일반 Claude·ChatGPT 웹 대화창에 이름만 입력하는 방식으로 설치되지는 않습니다. 사용할 프로그램과 계정이 아직 없다면 먼저 해당 제품을 준비해야 합니다. 팀에서 이미 사용 중이라면 어떤 프로그램을 쓰는지 담당자에게 확인하세요.

[AI 플러그인 설치 안내](guides/install.md)에 따라 `depromeet-plugin`을 설치합니다. 설치 명령을 어디에 입력해야 하는지 모르겠다면 안내의 준비 단계부터 읽으세요.

설치 후 같은 프로그램의 AI 대화창에서 다음 요청을 보냅니다.

```text
navigate-guide로 이 플러그인으로 할 수 있는 일을 설명해줘.
```

AI가 사용 안내를 읽고 기능과 시작 방법을 설명하는지 확인하세요. 다른 프로그램의 대화창을 열었거나 스킬을 찾지 못했다는 답을 받으면 설치 상태를 먼저 확인합니다.

## 2. 발표에 쓸 메모 준비하기

전달할 핵심 내용, 청중, 발표 시간을 적습니다. 파일로 제공해도 되고 대화창에 붙여 넣어도 됩니다. 숫자나 인용이 있다면 출처를 함께 제공하세요. 자료에 없는 성과를 AI가 사실처럼 추가하지 않도록 요청할 수 있습니다.

아래는 복사해서 바꿔 쓸 수 있는 요청 예시입니다.

```text
ask-depromeet로 계획을 세워줘.
팀 회의에서 쓸 5장짜리 발표자료가 필요해. 청중은 팀원이고 발표 시간은 5분이야.
아래 메모를 바탕으로 디프만 스타일의 발표자료를 만들고 싶어.
먼저 브라우저에서 열 수 있는 자료를 만들고, 저장 위치도 알려줘.
자료에 없는 숫자나 성과는 추가하지 마.

[여기에 메모를 붙여 넣으세요]
```

`ask-depromeet`는 작업 순서와 결과물, 사용자가 확인할 시점을 제안합니다. 이 계획을 읽고 진행 여부를 답하세요. 처음에는 HTML 제작까지만 요청하면 확인할 일이 줄어듭니다. HTML은 웹 브라우저로 열어 보는 파일 형식입니다.

## 3. 화면 구성과 문구 확인하기

계획을 승인하면 AI가 발표자료의 화면 구성 예시를 먼저 준비합니다. 파일 위치와 여는 방법을 받아 제목, 본문, 이미지가 놓일 자리를 확인하세요. 마음에 들지 않는 부분은 ‘본문 글자를 더 크게 해줘’처럼 구체적으로 요청합니다.

화면 구성을 확정한 뒤에는 모든 장표에 들어갈 문구를 확인합니다. 이때 빠진 내용, 잘못된 수치, 장표 순서를 고칩니다. 화면 구성 승인과 문구 승인은 서로 다른 단계이므로, 앞의 승인이 뒤의 내용을 자동으로 확정하지 않습니다.

## 4. 완성한 자료 열어 보기

AI가 전달한 폴더의 `index.html`을 웹 브라우저로 엽니다. 이미지·글꼴 등 함께 전달된 파일은 원래 폴더 구조를 유지하세요. HTML 파일만 다른 곳으로 옮기면 이미지나 글꼴이 빠질 수 있습니다.

모든 장표를 넘겨 보며 내용, 글자 잘림, 이미지 표시를 확인합니다. 문제가 있으면 해당 장표와 증상을 AI에게 알려 주세요. 이 단계의 결과물은 HTML 발표자료입니다. Figma 파일이나 PDF가 필요하면 아래 작업을 별도로 요청합니다.

## 5. 필요한 작업 이어가기

- 글자와 배치를 Figma에서 편집하려면 [Figma로 가져오기](guides/import-to-figma.md)를 따릅니다. Figma Desktop과 HTML → Figma 도구가 필요합니다.
- Figma의 장표를 발표 순서대로 묶으려면 [발표용 PDF 만들기](guides/export-pdf.md)를 따릅니다. Figma 원본 PDF와 Flow Inspector가 추출한 순서 정보가 필요합니다.
- 어느 단계인지 모르겠다면 [AI에게 사용법 물어보기](guides/ask-for-help.md)에 따라 지금 화면과 하려는 일을 설명합니다.
