# HTML 발표자료를 Figma로 가져오기

HTML → Figma 도구는 HTML 발표자료를 Figma의 장표로 가져옵니다. 텍스트와 일부 도형은 편집할 수 있지만 이미지나 복잡한 효과는 이미지 레이어로 들어가거나 원본과 다르게 보일 수 있습니다.

## 준비

Figma Desktop, 가져올 HTML 자료, 설치된 HTML → Figma 도구가 필요합니다. 처음 설치한다면 [Figma 도구 관리](figma-setup.md)를 먼저 따릅니다. Figma의 ‘프레임’은 장표 한 장을 담는 영역입니다.

이미지·글꼴·스타일 파일이 별도로 있는 자료는 관련 파일을 함께 ZIP으로 묶어야 합니다. ZIP은 여러 파일을 하나로 압축한 파일입니다. AI에 다음처럼 요청할 수 있습니다.

```text
convert-html-to-figma로 이 발표자료를 Figma로 가져올 준비를 해줘.
index.html과 관련 파일을 확인하고, 필요한 경우 폴더 구조를 유지한 ZIP으로 묶어줘.
실제 가져오기 전에 결과와 대상 Figma 파일을 확인하고 싶어.
```

## Figma에서 할 일

1. 가져올 대상 디자인 파일을 엽니다. AI가 준비한 결과와 변경할 대상을 확인한 뒤 가져오기를 승인합니다.
2. **Plugins → Development**에서 **HTML → Figma**를 실행합니다. 메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다.
3. `.html`, `.htm` 또는 `.zip` 파일을 선택합니다. 웹 주소를 입력하는 도구는 아닙니다.
4. 장표 미리보기를 확인하고, 필요한 경우 ↑ ↓로 순서를 바꿉니다.
5. **새 행으로 가져오기**를 누릅니다. 장표가 가로로 배치되고, 발표 화면에서 넘겨 볼 수 있는 ‘Flow’가 함께 만들어집니다.
6. 모든 장표의 글자·이미지·줄바꿈을 확인합니다. 텍스트를 선택해 편집되는지 확인하고 Prototype의 장표 연결도 살펴봅니다.

컴퓨터 조작 도구가 없는 AI는 Figma 안에서 대신 클릭할 수 없습니다. 이 경우 파일 준비는 AI가 돕고 위 조작은 사용자가 진행합니다.

## 결과가 다르게 보일 때

글꼴 대체 경고가 나오면 필요한 글꼴을 사용할 수 있는지 확인합니다. 복잡한 그림자나 효과는 완전히 재현되지 않을 수 있으므로 Figma에서 보정할 수 있습니다. 외부 웹사이트의 이미지·글꼴은 불러오지 않으니 자료 안에 파일이 포함되어 있는지도 확인하세요.

한 번 더 가져오면 기존 장표를 덮어쓰는 대신 아래에 새 행이 생깁니다. 수정한 자료를 다시 가져온 경우 사용할 행을 직접 확인하세요.

용량·장표 수 등 자세한 제한은 [변환 도구 안내](../../tools/figma-plugins/html-to-figma/README.md)를 참고하세요.
