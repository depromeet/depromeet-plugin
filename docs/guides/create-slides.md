# 메모로 발표자료 만들기

`create-slides`는 메모와 자료를 바탕으로 브라우저에서 열 수 있는 HTML 발표자료를 만듭니다. Figma 가져오기와 PDF 제작은 별도 작업입니다.

## 준비할 내용

발표 목적, 청중, 시간 또는 장표 수, 원본 메모를 준비합니다. 꼭 써야 하는 이미지나 문구가 있다면 함께 전달하세요. 저장할 폴더를 정했다면 요청에 포함합니다.

```text
create-slides로 팀 회의용 발표자료를 만들어줘.
청중은 팀원, 발표 시간은 5분, 장표는 약 5장이야.
디프만 19기 스타일을 사용하고, 작업 폴더 안의 meeting-slides에 저장해줘.
아래 메모의 사실을 유지하고 근거 없는 내용은 추가하지 마.
[메모]
```

## 진행 과정

1. **AI가 자료와 목적을 확인합니다.** 빠진 정보가 결과에 영향을 주면 질문할 수 있습니다.
2. **사용자가 화면 구성 예시를 확인합니다.** AI가 전달한 파일을 브라우저에서 열어 제목·본문·이미지의 배치를 봅니다. 수정할 내용을 말하고, 원하는 구성이 되면 승인합니다.
3. **사용자가 모든 장표의 문구를 확인합니다.** AI가 각 장표의 제목·본문·표 등을 제시합니다. 사실과 순서를 고친 뒤 승인합니다.
4. **AI가 최종 파일을 만들고 화면을 검사합니다.** 파일 위치와 확인한 범위를 안내합니다. 브라우저 검사가 불가능했다면 실제 검사 완료로 안내해서는 안 됩니다.
5. **사용자가 최종 자료를 열어 봅니다.** 전체 장표의 글자·이미지·순서를 확인합니다.

기본 결과물은 `index.html`과 필요한 이미지·글꼴 등입니다. 함께 전달되는 화면 구성 예시와 페이지 계획은 수정할 때 참고할 수 있습니다. 파일을 공유할 때는 관련 파일이 들어 있는 폴더 전체를 보관하세요. 다음 단계에서 Figma로 옮길 때도 이 파일들이 필요합니다.

글꼴을 받거나 표시하지 못하면 다른 글꼴이 사용될 수 있습니다. AI의 대체 안내를 확인하고 실제 화면에서도 글줄이 바뀌지 않았는지 보세요.
