# AI에게 사용법 물어보기

`navigate-guide`는 지금 하려는 일에 맞는 설명서를 찾아 안내합니다. 처음에는 전체 과정을 설명하고, 진행 중에는 막힌 단계와 다음 행동을 짚어 줍니다. 사용법을 묻는 것만으로 파일을 만들거나 Figma 문서를 변경하지 않습니다.

설치된 Claude Code 또는 Codex의 대화창에 다음처럼 요청하세요.

```text
navigate-guide로 안내해줘. 처음 쓰는 사람이야. 설치부터 발표자료 만들기까지 설명해줘.
```

```text
navigate-guide로 안내해줘. HTML 발표자료는 만들었고, 이제 Figma에서 글자를 고치고 싶어.
```

```text
navigate-guide로 안내해줘. Figma에서 플러그인이 열리지 않아.
설치 폴더를 옮겼고, 화면에 이런 오류가 나와: [오류 문구]
```

프로그램 이름, 이미 끝낸 단계, 화면에 나온 오류를 함께 적으면 안내가 구체적입니다.

## 설명을 듣고 실제 작업을 시작하려면

`ask-depromeet`에 작업 계획을 요청하거나 해당 작업 스킬에 직접 요청할 수 있습니다. `ask-depromeet`는 계획을 제안하고 승인을 받은 뒤 실행으로 이어갑니다. `navigate-guide`는 사용법 안내를 맡으므로 작업 계획 승인 단계를 반복해서 추가하지 않습니다.

```text
ask-depromeet로 이 메모를 5장짜리 발표자료로 만드는 계획을 세워줘.
```

설치된 스킬은 배포 버전에 맞는 GitHub 설명서를 참조합니다. AI가 문서를 읽을 수 없다고 알리면 제공한 링크를 직접 열거나, 해당 문단을 대화창에 붙여 넣어 설명을 요청하세요.
