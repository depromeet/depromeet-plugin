# Figma 장표를 발표 순서대로 PDF로 만들기

`extract-figma-slides`는 Figma에서 내보낸 PDF의 페이지를 확인해 발표 순서대로 묶습니다. Figma 화면에 놓인 순서와 실제 발표 순서는 다를 수 있으므로, 원본 PDF와 장표 연결 정보를 함께 사용합니다.

## 준비

Figma Desktop에서 대상 디자인 파일을 열고 [Depromeet Flow Inspector를 설치](figma-setup.md)합니다. 이 도구는 장표의 문구와 연결 정보를 읽으며, 장표 그림 자체를 PDF로 만드는 도구는 아닙니다.

## 사용자가 Figma에서 준비할 파일

1. 발표 장표가 들어 있는 **섹션**을 선택합니다. 섹션은 여러 프레임을 묶어 놓은 영역입니다.
2. **Plugins → Development → Depromeet Flow Inspector**를 실행합니다. 선택한 섹션을 읽고 `figma-slide-flow.json`을 내려받습니다. JSON은 AI가 장표 문구와 연결 관계를 읽는 정보 파일이며, 직접 내용을 고칠 필요는 없습니다.
3. **File → Export frames to PDF…**로 원본 PDF를 내보냅니다. 메뉴 이름은 앱 버전에 따라 다를 수 있습니다. 이 PDF는 수정하지 않고 보관합니다.
4. 두 파일과 발표 순서 메모를 AI에게 제공합니다. 발표에 쓰지 않을 시안이 있다면 알려 주세요.

```text
extract-figma-slides로 발표용 PDF를 만들어줘.
원본 PDF와 figma-slide-flow.json을 함께 제공할게.
발표 순서는 도입 → 진행 상황 → 다음 일정이야.
PDF 페이지와 장표를 대조해서 순서를 제안하고, 불확실한 장표는 확인해줘.
통합 PDF 한 개가 필요해.
```

## AI가 처리하고 사용자가 확인할 일

AI는 장표 문구·연결 정보와 원본 PDF의 페이지를 대조해 순서를 정합니다. 연결이 끊겼거나 포함 여부가 불분명한 장표는 사용자에게 확인해야 합니다. JSON에 나열된 순서만으로 원본 PDF 페이지 번호를 정하지 않습니다.

PDF 조립에는 Python과 Poppler라는 PDF 처리 도구가 필요합니다. 사용자는 직접 명령을 작성할 필요가 없지만, AI가 작업하는 컴퓨터에 도구가 없다면 먼저 설치 방법을 확인해야 합니다. 설치 가능 여부는 사용 환경에 따라 다릅니다.

완성된 PDF를 열어 전체 장표 수, 첫 장과 마지막 장, 구간이 바뀌는 지점을 확인하세요. 제외한 장표가 있다면 이유도 확인합니다. PDF는 정적인 페이지이므로 Figma의 클릭 동작이나 애니메이션은 유지되지 않습니다.
