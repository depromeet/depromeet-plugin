# Create Slides

Read and follow the [HTML slide workflow](references/workflow.md).

Choose a visual profile from the [profile index](profiles/INDEX.md) before
building a skeleton. Adapt its layouts to the user's material. Keep visual
rules inside the chosen profile. Deliver local HTML by default; PDF, PPTX, or
publication requires a separate explicit request.
