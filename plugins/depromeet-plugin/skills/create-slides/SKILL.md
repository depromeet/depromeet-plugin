# Create Slides

Read and follow the [HTML slide workflow](references/workflow.md).

Use the bundled Depromeet style as the starting direction. Adapt the layouts to
the user's material, but do not offer unrelated design presets. Deliver local HTML
by default; PDF, PPTX, or publication requires a separate explicit request.
