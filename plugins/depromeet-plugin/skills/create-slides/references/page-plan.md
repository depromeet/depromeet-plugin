# Page plan format

Create one `page-plan.md` per presentation. Use the user's language for labels and
copy while preserving stable IDs.

## Header

Record the purpose, audience, language, presentation or reading use, approximate
duration, canvas ratio, source authority, output path, and current review table
from [review-contract.md](review-contract.md).

## Deck overview

List every page in order:

| Page / revision | Layout / revision | Purpose | Review state |
| --- | --- | --- | --- |
| P01 / 1 | L01 / 1 | Introduce the presentation | proposed |
| P02 / 1 | L03 / 1 | Explain the first key point | proposed |

The overview is navigation. It does not replace the full page specifications.

## Page specification

For every page include:

1. Page ID, revision, layout ID, title, and purpose.
2. A row for every region in the selected layout.
3. Complete visual specifications.
4. Speaker notes when requested and source locators for factual claims.
5. Open issues and the current review state.

Use this region table:

| Region ID / name | Exact displayed content | Position and extent | Emphasis / reading order | Source or asset |
| --- | --- | --- | --- | --- |
| `context` / Section label | Partnership | L03 top label | Small / 1 | Presentation brief |
| `title` / Page title | What we can build together | L03 full-width heading | Largest / 2 | Proposed framing |
| `narrative` / Explanation | Exact paragraph shown on the page | L03 left 34% | Body / 3 | Supplied notes, p. 2 |
| `evidence` / Information cards | Card 1 title and value; Card 2 title and value | L03 right 66% | Cards / 4 | Supplied data |

For a chart, include its data, labels, units, and chart form. For a table, include
every visible header and cell. For an image, provide its path, crop, caption, and
alt text. For a diagram, list nodes, edges, and labels.

## Completion check

- Every page has a full specification.
- Every layout and region resolves to the confirmed skeleton.
- Every visible sentence is exact rather than a placeholder.
- Every visual can be built without inventing data or assets.
- Current page, layout, and style revisions are confirmed.
